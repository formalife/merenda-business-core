# Scripts

Gli script di automazione del progetto vivono qui.

Previsti inizialmente:

- `scan_channel.py` — censimento del canale;
- `ingest_video.py` — orchestrazione delle fasi 7–13;
- `transcript.py` — acquisizione/pulizia transcript;
- `extract_keyframes.py` — keyframe selettivi;
- `validate_project.py` — controlli semplici di coerenza e stato.

Gli script vengono implementati quando richiesto dalle fasi operative. Evitare automazione prematura o complessità non necessaria.
