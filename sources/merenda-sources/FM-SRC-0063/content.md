## Distillazione

Framework per AI customer-facing:
1. domande reali dei clienti;
2. posizionamento e prove dell'impresa;
3. memoria commerciale/dati collegati;
4. regole di risposta ed escalation.

Un file di procedure isolato non basta: l'assistente deve riconoscere contesto, storico e confini delle promesse.

Ciclo:
conoscenza verificabile + contesto → risposta → osservazione → correzione.

I riferimenti normativi e a specifiche piattaforme restano fuori dalla regola canonica.
