# Fondamenti

Questa sezione contiene i principi che governano l'intera Knowledge Base e l'ordine con cui gli altri nodi vanno interpretati.

## Ordine di lettura

1. **[Sistema operativo Merenda](sistema-operativo-merenda.md)** — mappa end-to-end della dottrina: mercato → cliente → posizionamento → offerta → autorità → domanda/canale → acquisizione/pre-educazione → vendita → esperienza → retention/referral → numeri/capacità → reinvestimento → espansione. Contiene dipendenze, gate, feedback loop e una procedura diagnostica per individuare il primo livello rotto senza saltare direttamente alla tattica.
2. **[Marketing first e principi di progettazione](marketing-first.md)** — principio generatore: il marketing orienta prodotto, servizio, processo e modello; ROI, risposta diretta, complessità, lungo periodo, analogico, prezzo premium e responsabilità strategica dell'imprenditore.

Il `sistema-operativo-merenda.md` è una sintesi di orientamento della dottrina già canonizzata, non una nuova fonte e non sostituisce i documenti specialistici. Quando un nodo specialistico contiene una formulazione più recente o più precisa, prevale quel nodo.
