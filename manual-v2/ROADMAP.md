# Manual V2 Roadmap

## Objective

Transform V1 from a complete doctrine-coverage artifact into a definitive professional manual that is:

- discursive and authorial;
- pedagogically structured;
- rich in meaningful examples;
- visually explanatory;
- quantitatively reproducible;
- operationally useful;
- doctrine-faithful;
- publishable.

V1 remains frozen as backend coverage baseline.

# Advancement rule

The project must optimize in this order:

**learnability → causal fidelity → authorial readability → operational transfer → production polish**

Coverage remains mandatory, but it is no longer mistaken for sufficient quality.
