# Manual V2 Roadmap

## Objective

Transform V1 from a complete doctrine-coverage artifact into a definitive professional manual that is:

- discursive and authorial;
- pedagogically structured;
- rich in meaningful examples;
- visually explanatory;
- quantitatively reproducible;
- operationally useful;
- doctrine-faithful;
- publishable.

V1 remains frozen as backend coverage baseline.

# Phase 6 — Golden chapters

**Status: NOT STARTED**

Select three stress-test chapters:

1. conceptual/foundational;
2. quantitative/economics;
3. procedural/commercial.

Each golden chapter must be produced nearly at final quality, including relevant:

- authorial prose;
- cases/examples;
- visuals;
- formulas;
- boxes;
- exercises/application;
- final-style layout.

Audits:

- doctrine;
- novice learning;
- editorial quality;
- visual quality;
- founder read test.

Gate:

**No production scaling until all three golden chapters are explicitly approved.**

# Advancement rule

The project must optimize in this order:

**learnability → causal fidelity → authorial readability → operational transfer → production polish**

Coverage remains mandatory, but it is no longer mistaken for sufficient quality.
