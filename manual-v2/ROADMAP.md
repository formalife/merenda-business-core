# Manual V2 Roadmap

## Objective

Transform V1 from a complete doctrine-coverage artifact into a definitive professional manual that is:

- discursive and human-authored in feel;
- systematic in Part → Chapter → Section → Paragraph hierarchy;
- theory-first, with examples subordinate to explanation;
- rich in meaningful examples without invented narrative scaffolding;
- visually explanatory;
- quantitatively reproducible;
- operationally useful;
- doctrine-faithful;
- publishable.

V1 remains frozen as backend coverage baseline.

# Advancement rule

The project optimizes in this order:

**logical hierarchy → conceptual clarity → natural readability → causal fidelity → operational transfer → production polish.**

Coverage remains mandatory, but coverage alone is never again treated as evidence that the manual is finished.
